# Tidal Cache

The application is aimed to allow a Tidal user to cache their favorite Tidal compositions
on a private computetr for offline listening.

Enjoy your favorite music privately!

# Disclaimer

This application is NOT intended for piracy. It uses a token that is generated 
by the official Tidal site.  
The user has to buy Tidal-HIFI subscription in order to download the music.

All the content downloaded by the application should be listened privately,
according to the Tidal's license agreement.

Never share or sell any content that is not intended for public sharing.

The author of this tool is not responsible for any misusage or any harm done to the user, their account or any other
people or property during the usage of the tool. Use it at your own risk.

# Usage

Install the application from the ()[releases]

Follow the instructions in the application's screen. You will need to:
1. Open a web page that the application requests (in tthe console window).
2. The page will directs you to Tidal site. Log in there with your subscribed account to receive a token.
3. Paste this token (as an "Oops" page's address string) into the application's window.
